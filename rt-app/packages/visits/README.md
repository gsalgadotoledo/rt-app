# Visits

Lightweight browser geometry and admin playback/heatmaps. Last 10 sessions, 120 points/session, 24-hour retention. No DOM/text/form capture. Browser entry: `./browser`; admin: `./admin`.

See the repository `rt-app/docs/components.md` and `rt-app/docs/observer.md` for setup, limits and examples.
