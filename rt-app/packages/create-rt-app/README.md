# @gsalgadotoledo/create-rt-app

```sh
npm create @gsalgadotoledo/rt-app my-app
cd my-app && npm run dev
```

Creates the project in a new folder, installs the pinned RT-App packages and makes an initial git commit. Options: `--template`, `--backend`, `--dir`, `--no-install`, `--no-git`, `--list`. Programmatic use and the templates live in `@gsalgadotoledo/rt-app-create`.
